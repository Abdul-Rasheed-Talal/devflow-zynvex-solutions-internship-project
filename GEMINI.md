# DevFlow Agent Instructions

Read `AGENTS.md` first. It is the primary engineering rulebook.

Use the repository documentation under `docs/` as the source of truth. Work only on the currently approved module. Use JavaScript, not TypeScript. Inspect existing code before editing. Make small, verifiable changes and do not add unnecessary dependencies.

The UI must look like a deliberate professional SaaS product: no gradients, decorative emojis, excessive rounded cards, flashy effects, random colors, or random web fonts.

After each meaningful task, verify the implementation and update `docs/PROGRESS.md`.
