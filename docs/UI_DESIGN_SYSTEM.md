# DevFlow — UI Design System

## Design direction
Professional developer-focused SaaS product. Clean, restrained, functional, and information-dense without looking visually noisy.

## Non-negotiable
- No gradients.
- No decorative emojis.
- No glassmorphism-heavy layouts.
- No excessive pill-shaped controls.
- No huge rounded cards used for every section.
- No random accent colors.
- No random web fonts.
- No flashy background animations.
- No generic AI-generated dashboard decoration.

## Typography
Use a system font stack. Do not import a web font unless explicitly approved.

## Color
Use neutral surfaces and text with one restrained primary accent. Define colors as reusable design tokens rather than hard-coding random colors throughout components.

## Components
Prefer:
- clear hierarchy
- subtle borders
- restrained shadows
- consistent spacing
- compact but readable controls
- obvious primary actions
- accessible focus states

## UX states
Every data-driven page/component should account for:
- loading
- empty
- success
- error

## Responsive design
Design desktop-first for productivity, but ensure core workflows remain usable on tablet and mobile widths.
