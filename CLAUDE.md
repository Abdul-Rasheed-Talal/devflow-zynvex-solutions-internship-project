# DevFlow Agent Instructions

Read `AGENTS.md` first. It is the primary engineering rulebook.

Before implementation:
- Read the relevant files under `docs/`.
- Inspect existing code.
- Confirm the task belongs to the current module.
- Do not invent requirements.

During implementation:
- Use JavaScript, not TypeScript.
- Keep changes focused and incremental.
- Follow the approved MERN architecture.
- Do not add unnecessary dependencies.
- Keep the UI professional: no gradients, decorative emojis, excessive rounded cards, flashy effects, or random fonts/colors.

After implementation:
- Run relevant checks.
- Verify the feature actually works.
- Update `docs/PROGRESS.md`.
- Report what changed and what remains.

Never use chat memory as a substitute for repository documentation.
